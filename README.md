# Legacy_Interop_Lab

Simple experiment and simulation involving legacy code and interoperability with other languages.

---

## Objective

This experiment simulates a legacy application: a monthly general ledger written in **COBOL**, accessible from modern code via a **C** bridge, a **C++23** extension, and simplified language bindings. The business logic is intentionally small; the project’s goal is *integration*—demonstrating how a legacy program, a C ABI, and various programming languages ​​can fit together, without the need for a build system that no one understands.
